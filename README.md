## 🔥 WHAT IS THIS?

**TJKT Smart Network 30** is a bold, high-energy **neobrutalist one-page website** for a networking solutions company. Built with a retro-futuristic "system console / mecha" aesthetic — thick black borders, hard offset shadows, yellow-on-black energy, and zero subtlety.

It's more than a landing page: it's a **playground of interactive features** that makes visitors feel like they're piloting a network command center.

---

## 🎯 FEATURES / CONTENT

| Zone | Description |
|------|-------------|
| **🖥 Hero Command** | Bold headline, live SLA/node/latency stats counters, and a live **WebGL-style particle network canvas** that reacts to your cursor |
| **📡 Layanan Kami** | 3 service cards — *Instalasi Jaringan*, *Konsultasi Jaringan*, *Konfigurasi Server* — with category filters & detail modals |
| **🧮 Estimator** | Interactive network cost calculator (service type + node count + SLA support → live IDR price) |
| **🛡 Tentang Kami** | Arsitektur / Keamanan / SLA tabs + a simulated **live network diagnostic console** with ping, jitter & packet-loss metrics |
| **💬 Testimoni** | Auto-playing client testimonial carousel |
| **🎮 NETGUESS Minigame** | A **terminal-style Wordle/RPG minigame** — guess 28 networking words (*ROUTER, MODEM, LINUX, DEBIAN, WIFI, MIKROTIK, FIREWALL*...) in 5 chances, with hints |
| **📧 Kontak** | Working contact form wired to **Web3Forms** → emails land in your inbox |
| **🤖 Chatbot** | Zapier AI chatbot embedded for instant visitor support |

## ⚙️ TECHNICAL STACK

```
├── index.html   → semantic structure & content
├── style.css    → full neobrutalist design system (CSS vars, offset shadows, keyframes)
├── index.js     → interactive logic (audio FX, calculator, diagnostics, carousel, minigame, motion engine)
└── images/      → logos & media assets
```

- **Zero frameworks.** Vanilla HTML / CSS / JavaScript.
- **Motion engine:** scroll-linked "fly-up & fade" reveals + entrance animations (framer-motion-style, built from scratch with `IntersectionObserver` + `requestAnimationFrame`).
- **Sound FX:** tactile neobrutalist "pop" sounds via the **Web Audio API**.
- **Accessible:** respects `prefers-reduced-motion`.
- **Responsive:** mobile drawer nav + adaptive grids.

## 🔧 CONFIGURATION

| Setting | Where |
|---------|-------|
| Contact form email | `index.js` → `WEB3FORMS_ACCESS_KEY` (grab key at [web3forms.com](https://web3forms.com)) |
| Hotline / email / address | `index.html` → `#contact` section |
| Quiz word list | `index.js` → `NETWORDS` + `NETWORD_HINTS` |
| Chatbot | `index.html` → `<zapier-interfaces-chatbot-embed>` (Zapier) |
| Theme colors | `style.css` → `:root` variables |
